# IMPORTANTE
Una vez clonado el proyecto, COPIAR el archivo .env y pegarlo en la carpeta BACKEND.

# EJECUCIÓN
Con la aplicación docker desktop abierta utilizamos el comando "docker compose up --build" dentro de la carpeta del proyecto.
Luego ya podemos ingresar a la pagina mediante los puertos:
- API/SWAGGER
- http://localhost:3000/api/docs
- Frontend
- http://localhost:4200
Para cerrar todo el docker se usa el comando "docker compose down"

## Descripción

Aplicación web full stack dockerizada para gestión de encomiendas.

El sistema incluye:

- Frontend Angular
- Backend NestJS
- Base de datos PostgreSQL
- Orquestación Docker Compose

---

## Tecnologías

- Angular
- NestJS
- PostgreSQL
- Docker
- Docker Compose
- Nginx
- TypeORM

---

## Arquitectura

Frontend → Nginx → Backend API → PostgreSQL

---

## Requisitos

- Docker Desktop

---
