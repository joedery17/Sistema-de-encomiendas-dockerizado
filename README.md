## Descripción

Aplicación web full stack dockerizada para gestión de encomiendas.

El sistema incluye:

- Frontend Angular
- Backend NestJS
- Base de datos PostgreSQL
- Orquestación Docker Compose

---

## Tecnologías

- Angular
- NestJS
- PostgreSQL
- Docker
- Docker Compose
- Nginx
- TypeORM

---

## Arquitectura

Frontend → Nginx → Backend API → PostgreSQL
